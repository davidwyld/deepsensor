    DataProcessor(folder=None, time_name='time', x1_name='x1', x2_name='x2', x1_map=None, x2_map=None, deepcopy=True, verbose=False)

    Normalise xarray and pandas data for use in deepsensor models.

    Parameters:

    Name Type Description Default
    folder str

    Folder to load normalisation params from. Defaults to None.

    		 None
    x1_name str

    Name of first spatial coord (e.g. "lat"). Defaults to "x1".

    		 'x1'
    x2_name str

    Name of second spatial coord (e.g. "lon"). Defaults to "x2".

    		 'x2'
    x1_map tuple

    2-tuple of raw x1 coords to linearly map to (0, 1), respectively. Defaults to (0, 1) (i.e. no normalisation).

    		 None
    x2_map tuple

    2-tuple of raw x2 coords to linearly map to (0, 1), respectively. Defaults to (0, 1) (i.e. no normalisation).

    		 None
    deepcopy bool

    Whether to make a deepcopy of raw data to ensure it is not changed by reference when normalising. Defaults to True.

    		 True
    verbose bool

    Whether to print verbose output. Defaults to False.

    		 False

    Normalise data.

    Parameters:

    Name Type Description Default
    data DataArray | Dataset | DataFrame | List[DataArray | Dataset | DataFrame]

    Data to be normalised. Can be an xarray DataArray, xarray Dataset, pandas DataFrame, or a list containing objects of these types.

    		 required
    method str

    Normalisation method. Options include: - "mean_std": Normalise to mean=0 and std=1 (default) - "min_max": Normalise to min=-1 and max=1 - "positive_semidefinite": Normalise to min=0 and std=1

    		 'mean_std'
